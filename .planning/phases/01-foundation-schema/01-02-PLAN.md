    1. Create `supabase/migrations/00000000000002_helpers_triggers.sql` with EXACTLY these from research §3 & §5:
       - `public.set_server_updated_at()` trigger function — sets NEW.server_updated_at = now() on INSERT/UPDATE
       - DO block that applies set_server_updated_at trigger to ALL tables that have a server_updated_at column
       - `rls_auto_enable()` event trigger — automatically enables RLS on any new table created in public schema. Uses `CREATE EVENT TRIGGER ensure_rls ON ddl_command_end`.
       - `private.visible_wallet_ids()` — SECURITY DEFINER, STABLE. Returns uuid[] of wallets the current user can see (own private wallet + shared wallet in their household). Uses `(SELECT auth.uid())` pattern for caching.
       - `private.user_household_id()` — SECURITY DEFINER, STABLE. Returns the current user's household_id from household_members where left_at IS NULL.
       - `public.handle_new_user()` trigger — AFTER INSERT on auth.users, creates a profile row with display_name from raw_user_meta_data.
       - `public.accept_invite(p_invite_token UUID)` — SECURITY DEFINER RPC function. Validates invite (not expired, not accepted, not revoked), adds user to household_members, updates profile.household_id, marks invite accepted, creates private wallet, seeds 8 default categories (Food, Transport, Shopping, Bills, Health, Entertainment, Education, Miscellaneous). Returns household_id. RAISE EXCEPTION on invalid invite.

    2. Create `supabase/migrations/00000000000003_rls_policies.sql` with ALL RLS policies from research §5:
       - REVOKE ALL from anon role on all tables and sequences
       - **profiles**: SELECT/UPDATE where auth.uid() = id
       - **households**: SELECT/INSERT/UPDATE where id = user_household_id() or created_by = auth.uid()
       - **household_members**: SELECT where household_id = user_household_id(), INSERT where user_id = auth.uid() OR household_id = user_household_id()
       - **household_invites**: ALL where household_id = user_household_id()
       - **wallets**: SELECT/INSERT/UPDATE where id in visible_wallet_ids() or household_id = user_household_id()
       - **wallet_categories**: ALL where wallet_id in visible_wallet_ids()
       - **Wallet-scoped tables** (transactions, transaction_presets, budgets, recurring_transactions, shopping_lists, investment_holdings, documents, debt_instruments, financial_goals, subscriptions, sip_schedules): ALL where wallet_id in visible_wallet_ids() — use DO loop per research §5
       - **User-scoped tables** (sms_rules, sms_merchant_mappings, notification_preferences): ALL where user_id = auth.uid() — use DO loop
       - **Household-scoped tables** (task_lists, calendar_events, important_dates): ALL where household_id = user_household_id() — use DO loop
       - **Child tables** (shopping_list_items via list→shopping_lists, tasks via list→task_lists, investment_transactions via holding→investment_holdings, debt_payments via debt_instrument→debt_instruments, goal_contributions via goal→financial_goals): ALL where parent FK exists in accessible parent
       - **Public data** (nav_history, price_history): SELECT only for authenticated
       - **sync_log**: ALL where user_id = auth.uid()

       Use `(SELECT auth.uid())` and `(SELECT private.visible_wallet_ids())` patterns (with SELECT wrapper) for per-statement caching as recommended.

  <name>Task 1: Drift table definitions for Phase 1 active tables</name>
  <files>lib/data/database/tables/profiles_table.dart, lib/data/database/tables/households_table.dart, lib/data/database/tables/household_members_table.dart, lib/data/database/tables/household_invites_table.dart, lib/data/database/tables/wallets_table.dart, lib/data/database/tables/wallet_categories_table.dart</files>
  <action>
    Create Drift table classes mirroring the Supabase schema column-for-column for the 6 Phase 1 active tables.

    **Column type mapping (Supabase → Drift):**
    - UUID → `TextColumn` (store as string, generate with `uuid` package)
    - TEXT → `TextColumn`
    - BIGINT (paise) → `IntColumn` (Drift uses Dart int which is 64-bit)
    - INTEGER → `IntColumn`
    - BOOLEAN → `BoolColumn`
    - TIMESTAMPTZ → `DateTimeColumn`
    - DATE → `DateTimeColumn`

    **Every table MUST have:**
    - `TextColumn get id => text()()` as primary key (UUID string)
    - `DateTimeColumn get createdAt => dateTime()()`
    - `DateTimeColumn get updatedAt => dateTime()()`
    - `DateTimeColumn get syncedAt => dateTime().nullable()()` (for synced tables)
    - `DateTimeColumn get deletedAt => dateTime().nullable()()` (for soft-delete tables)
    - `@override Set<Column> get primaryKey => {id};`

    **Note:** Drift tables do NOT have `server_updated_at` — that is a server-side concept. Local tables use `syncedAt` to track last sync.

    **File organization:**
    - `profiles_table.dart` → Profiles
    - `households_table.dart` → Households
    - `household_members_table.dart` → HouseholdMembers
    - `household_invites_table.dart` → HouseholdInvites
    - `wallets_table.dart` → Wallets (per research §4 example)
    - `wallet_categories_table.dart` → WalletCategories (per research §4 example)

    Use `.references(OtherTable, #column)` for FK relationships where practical. Use `.withDefault()` for boolean defaults and sort_order defaults. Use `.nullable()` for optional columns.
  </action>
  <verify>
    <automated>flutter analyze --no-fatal-infos lib/data/database/tables/</automated>
  </verify>
  <done>All 6 Phase 1 table definition files exist with every column from the Supabase schema mirrored. All PKs are TextColumn (UUID). No compile errors.</done>
</task>

       - `part 'category_dao.g.dart';`
